# Real-Time Weather Application 🌦️

A responsive web application built using **React** that provides real-time weather updates based on the user’s current location. The app integrates the **OpenWeather API** to fetch accurate weather data and offers a seamless user experience with dynamic geolocation features.

---

## Features 🚀

- **Real-Time Weather Updates**: Displays current weather conditions based on the user's location.
- **Geolocation Permissions**: Requests user permission to access location data.
- **Responsive Design**: Optimized for use across various devices, including mobile, tablet, and desktop.
- **Dynamic Updates**: Fetches and displays weather data dynamically whenever the location changes.

---

## Technologies Used 🛠️

- **React**: For building the user interface.
- **OpenWeather API**: For fetching weather data.
- **Geolocation API**: For obtaining the user's current location.
- **CSS**: For styling the application and ensuring responsiveness.
